# 🚀 Abhishek's Portfolio

A modern, futuristic portfolio website showcasing my projects, skills, and experience as a Software Engineer and Back-End Developer. Built with cutting-edge web technologies and featuring stunning animations, glassmorphism effects, and a cyberpunk-inspired design.

## ✨ Features

- **🎨 Futuristic Design**: Cyberpunk-inspired dark theme with neon cyan and purple accents
- **✨ Advanced Animations**: 
  - Glitch effects on text hover
  - Pulsing glow animations on interactive elements
  - 3D card tilt effects on project cards
  - Animated gradient backgrounds with moving grid lines
  - Smooth scroll behavior with offset for fixed header
- **📱 Fully Responsive**: Optimized for all devices from 4K monitors to mobile phones (320px+)
- **🎯 Interactive Elements**:
  - Animated text rotation (Software Engineer / Back-End Developer)
  - Hover effects with enhanced glows
  - Tab-based navigation in Resume section
  - Back-to-top button with pulsing animation
- **⚡ Performance Optimized**:
  - Reduced animations on mobile devices
  - Touch-friendly interface with 44px minimum touch targets
  - Lazy loading and optimized assets
- **🎭 Visual Effects**:
  - Glassmorphism on sticky header
  - Scanline overlay for retro CRT effect
  - Gradient borders with rounded corners
  - Timeline with pulsing nodes
  - Animated progress bars

## 📦 Installation & Setup

### **Prerequisites**
- Node.js (v16 or higher)
- npm or yarn

### **Installation**

1. Clone the repository:
```bash
git clone https://github.com/AbhishekS-381/Portfolio.git
cd Portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to:
```
http://localhost:5173
```

### **Build for Production**

```bash
npm run build
```

The production-ready files will be in the `dist` folder.

### **Preview Production Build**

```bash
npm run preview
```

## � Deployment to GitHub Pages

This project is configured for automatic deployment to GitHub Pages using GitHub Actions.

### **Automatic Deployment**

1. Push your code to the `main` branch:
```bash
git add .
git commit -m "Your commit message"
git push origin main
```

2. GitHub Actions will automatically:
   - Build the project
   - Deploy to GitHub Pages
   - Your site will be live at: `https://abhisheks-381.github.io/Portfolio/`

### **GitHub Repository Settings**

Make sure to configure GitHub Pages in your repository settings:

1. Go to **Settings** → **Pages**
2. Under **Source**, select **GitHub Actions**
3. The workflow will handle the rest automatically

### **Manual Deployment (Alternative)**

If you prefer manual deployment:

1. Install gh-pages:
```bash
npm install -D gh-pages
```

2. Deploy:
```bash
npm run deploy
```

**Note**: Update the `base` path in `vite.config.js` if your repository name is different from "Portfolio".
